# Stage 4d REACH (SPEC 8 AWAKENING: "Затаиться и переждать пик — рабочая стратегия"; awakening.searchRadius): the
# rule a player can learn. A player whose noise tops the anger out, who then sneaks about 12-13 blocks away from where
# the noise was and keeps still, is not taken: the entity rushes to the last sound, searches only searchRadius (4)
# around it, which with its reach (8) does not find the player, and its roam keeps away from the player. A player who
# stays at the noise is taken. The noise is real: the anger is set to 99.5 by command (HUNTING), and a step of a
# sprint on stone, heard about 50 blocks away, tops it out. The entity is that far so that the player, sneaking at
# 1.3 blocks a second, is 11-12 blocks from the noise when the entity (6.3 blocks a second) gets there.
# 1. Sprint north, then sneak on north (away from the entity), 12.5 blocks from the last step, and keep still.
# 2. Sprint north, then sneak 13 blocks west (across the entity's way) and keep still.
# 3. Sprint north, then stand at the noise: reached, the build-up starts.
# The seeking is shortened to 20 s (awakening.seekSeconds; the search runs 20 s after the last sound anyway). Parts 1
# and 2 end with "stage hunting" in /tremor info and "No Awakening here" from /tremor awaken stop (the server log has
# "reached nobody within 20 s"), part 3 with "Awakening #... for Dev stopped" (the log has "has reached Dev").
# Uses the sky platform of stage3-aggression.txt (repaired here).
# Run: tools/gradle-locked.sh runClientAutotest -Ptremor_autotest_script=stage4d-reach-sneakaway.txt

waitchunks
cmd gamemode spectator
cmd difficulty normal
cmd time set noon
cmd gamerule doDaylightCycle false
cmd gamerule doMobSpawning false
cmd effect give @s minecraft:night_vision infinite 0 true
cmd tremor awaken stop
cmd tremor restore
cmd tremor despawn
cmd kill @e[type=!player]
cmd tp @s 300.5 201.0 310.5 180 8
wait 40
waitchunks

# An Awakening that starts must not swallow the player before the script stops it

config awakening.seekSeconds 20
