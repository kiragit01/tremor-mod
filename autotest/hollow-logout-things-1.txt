# Leaving the game inside the hollow with things on the cursor and in the crafting grid (the review, И8 and А4): they
# go back into the inventory, and what does not fit lies where the player comes back, a shard too (the ground takes
# the shards of a dead player only). Part 1: 35 swords (one slot free), into the hollow, five diamonds on the cursor
# and two shards in the crafting grid there, and quit while inside. Part 2 (hollow-logout-things-2.txt, run next)
# looks at what the player has and what lies at 860.5 201 300.5.
# (The cursor and the grid are set by commands of 1.20.5 and later: these two scripts are not on the Forge 1.20.1
# branch.)
# Run: gradlew runClientAutotest -Ptremor_autotest_script=hollow-logout-things-1.txt
waitchunks
cmd gamerule commandModificationBlockLimit 2147483647
cmd gamemode spectator
cmd time set noon
cmd tremor despawn all
cmd tremor awaken stop
cmd tremor restore
cmd kill @e[type=!player]
cmd tp @s 860.5 202.0 300.5
wait 40
waitchunks
cmd fill 840 194 280 880 199 320 minecraft:dirt
cmd fill 840 200 280 880 200 320 minecraft:grass_block
cmd fill 840 201 280 880 230 320 minecraft:air
cmd kill @e[type=!player]
cmd tp @s 860.5 201.0 300.5 0 30
cmd gamemode survival
cmd clear @s
cmd effect clear @s
cmd effect give @s minecraft:instant_health 1 4 true
cmd give @s minecraft:iron_sword 35
wait 10
cmd tremor hollow enter
wait 160
waitchunks
cmd data get entity @s Dimension
cmd item replace entity @s player.cursor with minecraft:diamond 5
cmd item replace entity @s player.crafting.0 with tremor:tremor_shard 2
wait 5
quit
