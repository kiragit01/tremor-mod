# A series of echo rings (1.4.0, the user: two or three while it hears nobody). /tremor echo: the nearest tremor
# draws in and sends its echo; while a ring finds nobody and it hears nothing it draws in again and sends another,
# up to echo.rings (3). 1. the player out of reach: three rings in a row ("found nobody, it sends another" twice);
# 2. a second /tremor echo while a ring runs is refused; 3. the player standing within reach: found by the first,
# no more rings.
# Run: gradlew runClientAutotest -Ptremor_autotest_script=echo-series.txt
waitchunks
cmd gamemode spectator
cmd time set noon
cmd tremor despawn all
cmd kill @e[type=!player]
cmd tp @s 860.5 215.0 300.5
wait 40
waitchunks
cmd fill 800 195 260 920 199 340 minecraft:dirt
cmd fill 800 200 260 920 200 340 minecraft:grass_block
cmd fill 800 201 260 920 230 340 minecraft:air
cmd kill @e[type=!player]
config ambush.enabled false
config echo.range 32
config echo.rings 3
cmd tremor spawn 860 200 300
cmd tremor stage alert
cmd tremor anger 35
cmd gamemode survival
cmd effect give @s minecraft:resistance 600 4 true
log --- 1. out of reach: three rings
cmd tp @s 905.5 201.0 300.5 90 10
wait 40
cmd tremor echo
wait 40
log --- 2. again while a ring runs: refused
cmd tremor echo
wait 460
cmd tremor info
log --- 3. within reach: found by the first, no more
cmd tp @s 875.5 201.0 300.5 90 15
wait 60
cmd tremor echo
wait 300
cmd tremor info
cmd tremor despawn all
config ambush.enabled true
quit
