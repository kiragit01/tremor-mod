# A tremor led about over the world as it was generated, first on the surface, then through caves: the player hops
# to a random spot of ground some blocks off (spreadplayers), the tremor is sent there, again and again. No
# picture is judged: the renderer counts every copy that came or went at a height and every jump of the ground
# (pops, POPS lines in the report), where the eye would catch a harsh change on rough ground (the user). A shot at
# every stop shows where it was.
# Run: gradlew runClientAutotest -Ptremor_autotest_script=pops-wild.txt
waitchunks
cmd gamemode spectator
cmd time set noon
cmd weather clear
cmd tremor despawn all
cmd tremor awaken stop
config ambush.enabled false
config stalactites.enabled false
config listeners.enabled false
config spawn.enabled false
hud off
log --- surface
cmd tp @s -700 140 -700
wait 60
waitchunks
cmd execute at @s run spreadplayers ~ ~ 0 16 false @s
wait 20
waitchunks
cmd tremor spawn ~ ~-1 ~
cmd tremor ai off
cmd tremor stage hunting
cmd tremor hold
wait 40
pops on
cmd execute at @s run spreadplayers ~ ~ 0 22 false @s
wait 5
cmd tremor goto ~ ~-1 ~
cmd data get entity @s Pos
