# Главные настройки Tremor

Файлы: `config/tremor-common.toml` (игра и сервер) и `config/tremor-client.toml` (только вид и звук, у каждого
игрока свой). Над каждым ключом в файле есть комментарий на английском. Здесь — то, что крутят чаще всего.

После обновления мода старые значения в файле остаются как были: чтобы получить новые значения по умолчанию, удали
файл, он создастся заново.

## Клиент (`tremor-client.toml`)

| Ключ | Что делает |
|---|---|
| `render.quality` | Пресет для слабых ПК: `LOW` / `MEDIUM` / `HIGH` |
| `render.style` | Вид бугра: `BLOCKS` (сдвигаются блоки) или `WARP` (гладкий холм) |
| `effects.hollowFogDistance` | Дальность видимости в изнанке (блоки) |
| `sound.*Volume` | Громкость шороха, гула, сердцебиения, затягивания |

## Появление (`spawn`)

| Ключ | Что делает |
|---|---|
| `enabled` | Появляется ли тварь сама |
| `dimensions` | В каких измерениях (по умолчанию обычный мир и ад) |
| `checkIntervalSeconds`, `baseChance` | Как часто и с каким шансом проверяется появление |
| `caveMultiplier`, `darkMultiplier`, `deepMultiplier`, `nightMultiplier` | Во сколько раз чаще в пещере, в темноте, глубоко, ночью |
| `cooldownSeconds` | Пауза после ухода твари |

## Слух (`hearing`)

| Ключ | Что делает |
|---|---|
| `threshold` | С какой громкости тварь слышит (меньше — слышит дальше) |
| `maxDistance` | Дальше этого не слышит никогда |
| `angerPerLoudness` | Сколько злости даёт звук |
| `loudness`, `sprintStepLoudness` | Громкость событий: шаг, приземление, снаряд, взрыв, бег |
| `rustlingFactor` | Насколько громче шаг по листве |
| `mobLoudnessFactor`, `mobAngerFactor` | Слышит ли животных и насколько они её злят |

## Поведение (`behavior`)

| Ключ | Что делает |
|---|---|
| `alertAt`, `huntAt`, `awakenAt` | Пороги злости: настороженность, охота, пик |
| `decayPerSecond` | Как быстро остывает |
| `alertListenFactor` | Во сколько раз лучше слышит, когда замерла и пустила рябь |
| `stages.*.speedFactor` | Скорость по стадиям |
| `wanderKeepAway` | Держит ли дистанцию от игроков на охоте |
| `netherSpeedFactor`, `netherAngerFactor` | Насколько она злее в аду |
| `contact.damage`, `contact.devourMobs` | Урон при ударе; поглощает ли мобов |

## Пробуждение (`awakening`)

| Ключ | Что делает |
|---|---|
| `radius`, `buildupSeconds`, `buildupDrag` | Размер зоны, время на побег, насколько земля держит за ноги |
| `reachDistance`, `seekSeconds`, `searchRadius` | Как близко надо подобраться, сколько ищет на пике, где обыскивает |
| `lethal` | Смерть при поражении (или мягкий исход) |
| `craterRadius`, `craterDepth` | Размер кратера (0 — без кратера) |

## Изнанка (`hollow.level`)

| Ключ | Что делает |
|---|---|
| `breathSeconds` | Сколько времени есть в изнанке |
| `nodeMinDistance`, `nodeMaxDistance` | Как далеко узел |
| `closeSpeed`, `graceSeconds` | Скорость смыкания и пауза перед ним |
| `digFactor` | Скорость копания внутри |

## Вещи (`items`)

| Ключ | Что делает |
|---|---|
| `shardsMin`, `shardsMax` | Сколько осколков даёт узел |
| `geophoneRange`, `seismographRange` | Дальность геофона и сейсмографа |
| `muffledStepsFactor` | Громкость шагов в «тихих» ботинках |
| `frenzy*` | Бешенство от брошенного осколка: скорость, высота, время |

## Движение (`movement`)

| Ключ | Что делает |
|---|---|
| `speed` | Базовая скорость бугра |
| `maxDiveDepth` | Насколько глубоко ныряет сквозь породу |
| `leapDormant` … `leapFrenzy` | Через какой зазор воздуха перепрыгивает на каждой стадии |
